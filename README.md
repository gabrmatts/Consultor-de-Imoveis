# 🏢 Mini Site - Consultor Imobiliário

 Um mini site premium, minimalista e de alta conversão desenvolvido para consultores imobiliários apresentarem seus principais imóveis, capturarem leads e facilitarem o contato direto via WhatsApp.

---

## ✨ Demonstração & Design

O projeto foi construído com foco em **UI/UX premium e minimalista**, inspirado nas interfaces modernas de grandes startups (como Stripe, Linear e Notion).

*   **Design Responsivo:** Totalmente otimizado para dispositivos móveis, tablets e desktop.
*   **Tipografia Limpa:** Utilização de fontes modernas para garantir excelente legibilidade.
*   **Ícones Fluidos:** Interface integrada com a biblioteca **Lucide Icons** para um visual leve e minimalista.

---

## 🚀 Funcionalidades

*   📱 **Seção Hero de Alto Impacto:** Apresentação clara do consultor com chamada para ação (CTA) imediata.
*   📂 **Vitrine de Imóveis:** Listagem de propriedades em destaque com cards limpos, organizados por categorias (Ex: Venda, Locação, Lançamentos).
*   💬 **Integração Direta com WhatsApp:** Botões de CTA direcionando o cliente para conversas personalizadas com mensagens dinâmicas baseadas no imóvel escolhido.
*   📍 **Seção Sobre Mim & Localização:** Espaço para autoridade do consultor e mapa de atuação.

---

## 🛠️ Tecnologias Utilizadas

Este projeto foi desenvolvido utilizando tecnologias puras (Vanilla) para garantir o máximo de performance, SEO e carregamento instantâneo:

*   **HTML5** - Estruturação semântica.
*   **CSS3** - Estilização moderna utilizando CSS Variables (Custom Properties), Flexbox e Grid.
*   **JavaScript (ES6)** - Manipulação de DOM para filtros dinâmicos e máscaras de formulário.
*   **Lucide Icons** - Biblioteca de ícones vetoriais leves.
